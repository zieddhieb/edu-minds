# Photos des composants (EduMinds)

Déposez ici les photos des composants au format `.jpg`.

### Nom des fichiers :
Le nom du fichier doit correspondre exactement à la référence du composant :
- `CMP001.jpg` (Résistance 10 Ω)
- `CMP003.jpg` (Résistance 220 Ω)
- `CMP005.jpg` (Résistance 1 kΩ)
- `CMP007.jpg` (Résistance 10 kΩ)
- `CMP011.jpg` (Potentiomètre 10 kΩ)
- `CMP018.jpg` (LED rouge)
- `CMP037.jpg` (Bouton poussoir)
- `CMP039.jpg` (Interrupteur à glissière)
- `CMP046.jpg` (Plaque d'essai / breadboard)
- `CMP049.jpg` (Cavalier mâle-mâle)
- `CMP052.jpg` (Fil rigide)
- `CMP059.jpg` (Alimentation DC)
- `CMP065.jpg` (Régulateur 3,3 V)
- `CMP068.jpg` (Fusible 500 mA)
- `CMP070.jpg` (Multimètre)
- `CMP083.jpg` (Capteur analogique 3,3 V)

### Comment activer l'affichage d'une photo :
Dans le fichier `src/data/components.csv`, changez la dernière colonne `photo` de `no` à `yes` pour la ligne correspondante.
Si `photo` est à `no`, l'application affiche un badge avec le nom et la référence du composant.
